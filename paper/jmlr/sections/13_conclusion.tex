\section{Conclusion}
\label{sec:conclusion}

In this paper, we investigated reinforcement learning plasticity across intermediate foundation model checkpoints. We demonstrated that pre-RL readiness signals—most notably gradient alignment between NTP loss and policy gradients—predict subsequent RL capability gains. We introduced CARLS, an adaptive scheduler that dynamically adjusts compute allocation based on real-time checkpoint readiness. Empirical multi-seed evaluations show that CARLS achieves superior compute-normalized performance while preserving essential solution diversity.
