## 1. Executive Summary & Audit Mandate

An independent scientific integrity audit identified that prior experimental scripts in this repository generated synthetic or simulated measurements while presenting them as empirical evidence. Specifically:

1. `scripts/run_full_plasticity_study.py` and `scripts/run_pretrained_plasticity.py` mathematically constructed the dependent variable (`rl_gain`) directly from predictor variables (`gradient_alignment`, `policy_entropy`, `pre_pass1`) using hard-coded formulas (e.g., `0.42 * grad_align + 0.35 * entropy - 0.25 * pre_pass1`) and Gaussian noise (`np.random.normal`).
2. `scripts/run_real_baselines.py` hard-coded target Pass@1, Pass@4, FLOPs, retention scores, and diversity ratios, adding Gaussian noise to simulate baseline runs.

**RULE ZERO ENFORCEMENT:** All synthetic metrics, correlations, p-values, R² scores, FLOP savings, and retention values derived from these scripts are **invalid for scientific publication** and must be quarantined. No simulated result will be presented as empirical evidence in paper manuscripts or documentation.

## 3. Remediation & Scientific Record Repair Protocol

1. **Quarantine:** All synthetic scripts and outputs are relocated under `experiments/synthetic_validation/` and clearly marked with `SYNTHETIC_ONLY.md`.
2. **Manuscript Retraction:** All numerical claims in `paper/jmlr/` and `README.md` depending on synthetic data are set to `RESULT NOT YET EMPIRICALLY ESTABLISHED`.
3. **Publication Status:** Paper publication status is set to:
   `JMLR STATUS: NOT READY — REAL EXPERIMENTS REQUIRED`.
4. **Empirical Pipeline Implementation:** A genuine, end-to-end empirical pipeline (`scripts/run_real_empirical_pipeline.py`) is implemented to load real open models (`SmolLM-135M`, `distilgpt2`), create real checkpoint parameter states, measure genuine forward-pass diagnostics ($\mathcal{L}_{\text{NTP}}$, $H(\pi_\theta)$, $\cos(\mathbf{g}_{\text{NTP}}, \mathbf{g}_{\text{RL}})$), execute real GRPO RL updates ($R^*$), evaluate real post-RL Pass@k, and store raw generation logs under `artifacts/empirical/`.
5. **Provenance Validation:** All empirical artifacts must pass `scripts/validate_empirical_artifacts.py` before inclusion in scientific manuscripts.
